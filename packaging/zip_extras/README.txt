PERC Studio {version} - portable ZIP
==========================================

Accelerates data center modeling for transmission planning
engineers: builds documented PSS/E dynamic load models for large
data-center-class loads. Windows 10/11 (64-bit); no installation,
administrator rights or internet connection needed.

1. Extract this ZIP to a folder you keep (for example Documents or
   C:\Tools). Do not run the app from inside the ZIP.
2. Double-click "Create Desktop Shortcut.cmd" once. It puts a
   "PERC Studio" shortcut on your desktop.
3. Start the app from the desktop shortcut (or run
   "PERC Studio.exe" in this folder).

The Documentation tab inside the app has the user guide, the model
reference, the ride-through preset library and the known limitations.

Neither PSS/E nor the PERC1 or PERC2 user-defined model DLLs (ISO-NE)
are included with, or distributed by, this application.

Questions and bug reports: https://github.com/TimThacker/perc-studio/issues
(please include the version shown on the app's About page).
